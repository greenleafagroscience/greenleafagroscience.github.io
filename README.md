# Green Leafagro Science website

A responsive, static product-catalogue website prepared for `greenleafagroscience.com`.

## Preview locally

Open `index.html` in a browser, or run a small local web server from this folder:

```bash
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.

## Publish with GitHub Pages

1. Extract the upload ZIP on your computer.
2. In the empty `greenleafagroscience.github.io` repository, choose **Add file > Upload files**.
3. Drag all extracted files and the `assets` folder into the upload page. `index.html` must appear at the repository root, not inside another folder.
4. Choose **Commit changes**.
5. Open **Settings > Pages**.
6. Under **Build and deployment**, choose **Deploy from a branch**, `main`, and `/ (root)`, then save.
7. The included `CNAME` file records `greenleafagroscience.com`; also enter that domain under **Settings > Pages > Custom domain** after the first deployment.
